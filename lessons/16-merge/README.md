# Урок 16 — ветка fix и слияние с конфликтом

В этой папке отдельный пример проекта. Ветка `fix` исправляет подвал, а `main` параллельно готовит выпуск. Обе ветки меняли одну и ту же строку файла `merge-demo.txt`, поэтому Git остановил автоматическое слияние и попросил разрешить конфликт.

## Что сделано

1. Создана базовая версия файла в `main`.
2. Ветка `fix` исправила статус подвала.
3. В `main` появилась другая правка той же строки.
4. `git merge fix` показал конфликт.
5. Конфликт разрешён вручную: итог содержит оба смысла, после чего создан merge-коммит.

История видна командой:

```bash
git log --oneline --graph --decorate
```

В VS Code конфликт обычно открывают через **Source Control → Merge Changes**, выбирают нужные фрагменты и сохраняют объединённый вариант. После этого:

```bash
git add lessons/16-merge/merge-demo.txt
git commit
```
