# Урок 19 — настройки редактора

`.vscode/extensions.json` рекомендует нужное проекту расширение. Персональную синхронизацию включают отдельно в VS Code: значок Accounts → **Turn on Settings Sync** → выбрать настройки, расширения и другие данные для синхронизации.

В этой папке нет токенов или личных настроек. В репозиторий попадает только рекомендация расширения.
